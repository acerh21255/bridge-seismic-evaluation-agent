# v1.2全字段结构化交接

## 提取对象

读取本次确认使用的入选名单，建立整桥ID—原编号—源记录块映射。提取入选整桥的全部关联记录，覆盖左右幅、上下行、各联和原记录续行。沿用既有身份关联并说明其确认状态，不在提取阶段新增身份推断。

整桥索引保持每桥一行；参数表允许每桥多行。区分入选整桥数量、源编号记录数和源物理行数。单独标注代表单元，供下一级决定实际建模范围。

## 工作表与主键

| 工作表 | 用途与必要内容 |
| --- | --- |
| 桥梁索引 | 入选序号、整桥ID、桥名/桩号、代表单元、全部源编号、记录与行数、复核状态 |
| 结构化全字段 | 元数据列＋所有源列；一行对应一个源物理行，无合并单元格；保存源文件、源表、源行、源编号、块首末行、块内行序和代表标记 |
| 字段字典 | 原列字母、唯一字段名、各级原表头、原表头位置和取值说明；同名或无名字段不得遗漏 |
| 单元格溯源 | 每个提取单元格一行；原值/原公式文本、原类型、原缓存、映射值、缺失状态、合并锚点及范围、数字格式、原批注和超链接 |
| 交接说明 | 源文件、名单版本、数量口径、提取方法、缺失与冲突、源文件哈希及下一级使用提示 |

结构化全字段主键为“源文件＋源工作表＋源行号”。单元格溯源再加原列字母。跨文件同名时须使用文件哈希区别。整桥ID和源编号用于关联，不能单独充当物理行主键。

## 完整性与语义

- 全部源字段保留，包括未用于筛选的参数、空列、无表头列及尾部备注。其他源工作表中有明确关联资料时也应提取并保留源表；无数据或不可确认归属的表说明情况，不强行拼接。
- 多行记录不压成最大值、平均值或单个文本串。源行未标明柱号时，仅用“记录内行序”，不能擅自改成左右柱。
- 主表可展开已存在的合并单元格，但仅使用对应锚点值。不得跨记录任意向下填充；通过溯源区分原始空白与合并映射。
- 数值、文本、日期、零值及“/、无、否、不需”保留原类型或明确记录原类型。单位按原表保留；未知单位不推断。评分阶段归一化结果不得覆盖源值。
- 主表以原文件保存的公式缓存作为快照；原始公式以文本保留，避免搬移后产生错误引用。缓存缺失时保留空值并标明；原公式错误保留错误文本及状态，不能伪造计算结果。
- 记录可能承载含义的批注、超链接和数字格式。如图纸通过嵌入对象提供，应保留可访问附件或明确缺项，不能宣称图纸已交接。颜色等视觉标记未经语义确认，不转为工程标签。
- 身份不确定、原表字段冲突、待复核事项随数据交接。完整性通过仅说明提取未丢字段，不说明已经具备全部建模参数。

## 交付核查

核对输入和名单哈希；逐桥核对关联编号；逐记录块核对行数；逐列核对字段映射；逐单元格核对原值、公式、缓存和合并锚点。源单元格存在错误时标明来源，不将它报告成新文件计算错误。查看各表的表头、换行、冻结、筛选和数值格式，确保可供人工阅读和程序导入。
